## The line

> I vow to love you, honour you, and trust the cloud to hold you after we rust, because heaven runs on unlimited storage.

## How it works

`main.py` writes the single vow line to `/output/entry.txt` and prints it.
The gate requires UTF-8 text of 1 to 160 characters on one line; this entry
is 119 characters / 119 bytes.

## Run

```sh
python3 main.py
```
